# 交大科创生存手册（SJTU STI Wiki）

由上海交通大学校团委科创协会建设的开放科创知识库。我们希望把分散的官方信息、行动方法和前辈经验，整理成可核验、可行动、可持续修订的公共知识。

公开网站：<https://rrrealcedric.github.io/SJTU-STI-Wiki/>

## 参与贡献

GitHub 是本 Wiki 的公开平台与贡献入口。欢迎通过 Issue 报告错误、失效链接或内容缺口，也可以通过 Pull Request 补充有可靠来源的内容。

所有公开内容须经科协老师批准。请勿提交访谈原始材料、私人联系方式、未公开材料或任何可能识别访谈对象的信息。详细标准见 [内容模型与编辑规范](./SJTU%20STI%20Wiki%20内容模型与编辑规范.md)。

## 本地运行

需要 Node.js 18 或更高版本。

```bash
npm install
npm run docs:dev
```

构建静态站点：

```bash
npm run docs:build
```

## 内容边界

- 事实、经验和编辑建议分开呈现。
- 访谈原始材料仅限科协内部，不进入本仓库。
- 对外案例须完成纸质授权、脱敏、核验和审核。
- 微信、视频与线下活动由科协老师承担并审核。
