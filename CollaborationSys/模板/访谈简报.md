# 访谈简报模板

> 填写后的简报只存放在科协内部受控资料库。公开仓库保留空白模板。

| 字段 | 填写内容 |
| --- | --- |
| Source ID | `INT-___` |
| 核心知识缺口 | 读者具体遇到什么问题？当前 Wiki 哪些内容不足？ |
| 为什么需要访谈 | 哪些过程信息无法从官方公开材料获得？ |
| 嘉宾代号与选择依据 | 相关直接经历、可讲述的判断过程；真实联系方式另存 |
| 路径及候选页面 | `R/C/P/S/T` 槽位或 `UNPLACED` |
| 已知公开资料 | 标题、公开网址、核验日期；不写受限链接 |
| 希望得到的知识单元 | 预期卡片主题、可能的反例和资源线索 |
| 访谈负责人、主访与记录人 | 指定单一联络人及两名执行角色 |
| 拟访谈日期与时长 | 日期；预计 1–2 小时 |
| 纸质授权状态 | 待确认 / 已确认；记录内部归档编号 |
| 不追问或不公开边界 | 嘉宾与第三方的隐私、敏感主题、未公开事项 |

## 访谈前决定

- [ ] 选题是公共知识缺口，不只是人物介绍。
- [ ] 官方可核验事实已先行查找。
- [ ] 嘉宾已知晓访谈用途、记录方式和各渠道授权边界。
- [ ] 授权和记录设备在访谈前得到明确确认。
