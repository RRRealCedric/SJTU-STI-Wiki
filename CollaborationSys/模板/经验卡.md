# Experience Card 模板

> 填写后的经验卡属于内部工作材料。保持一句话陈述与原语境的对应关系，不粘贴长段逐字稿。

| 字段 | 填写内容 |
| --- | --- |
| Card ID | `E-___-__` |
| Source ID | `INT-___` |
| Timestamp | `mm:ss–mm:ss` 或记录页码 |
| Extractor |  |
| Statement | 受访者实际说出的经验、动作或判断，用一句话表达 |
| Type | `FACT / EXP / METHOD / JUDGEMENT / WARNING / RESOURCE` |
| Context | 影响理解的背景与约束，尽量使用非识别性描述 |
| Applicability | 对谁、在什么条件下有参考价值；反例是什么 |
| Tags | 受控主题词，用英文分号分隔 |
| Candidate Pages | 页面 ID；无法分类用 `UNPLACED`，建议新专题用 `NEW_PAGE` |
| Verify | `YES / NO / PENDING` |
| Status | 新卡填 `RAW` |
| Confidence（可选） | `A / B / C / D`，参见字段字典 |
| Relation（可选） | `supports:E-___-__` 或 `conflicts:E-___-__` |

## 脱敏示例

`Statement`：第一次进入课题组时，了解日常带教者和指导频率有助于判断是否适合自己。

`Type`：`JUDGEMENT`　`Context`：受访者入组初期缺少固定指导，后来调整了合作方式。

`Applicability`：缺少独立研究经验、需要明确反馈机制的本科生。`Confidence`：`C`。

## 常见误用

不要把“某人当时没有得到带教”写成“该类课题组都不重视本科生”。单一经历先作为带条件的卡片，是否能综合为建议由 Node Editor 判断。
