# 页面槽位与现有页面

`Page ID` 是经验卡归类和发布队列的稳定编号。它先描述内容范围，只有 `EXISTING` 才表示已有独立网页。`SECTION` 表示内容目前包含在汇总页内，独立页面仍未建立。页面负责人在总表 `Pages` 中指定。
