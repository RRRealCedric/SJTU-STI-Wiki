# 字段与状态

私有总表只有五个工作表。跨表引用用 ID，不用行号；一行代表一个来源、卡片、节点、页面槽位或发布动作。字段中不要粘贴录音、逐字稿、个人联系方式或受限共享链接。

## Sources

`Source ID`、`来源类别`、`知识缺口`、`嘉宾代号`、`访谈日期`、`负责人`、`授权记录编号`、`授权状态`、`资料库编号`、`处理状态`、`备注`。

`Source ID` 为 `INT-001` 等。嘉宾真实身份、联系信息、纸质授权原件和原始材料位置由受控资料库另行管理。总表只保留可以关联的内部编号。

## Cards

十二个核心字段：`Card ID`、`Source ID`、`Timestamp`、`Extractor`、`Statement`、`Type`、`Context`、`Applicability`、`Tags`、`Candidate Pages`、`Verify`、`Status`。另有可选字段 `Confidence` 和 `Relation`。

- `Card ID`：`E-001-01`，中间编号对应 `INT-001`。
- `Timestamp`：原始材料内的时间范围，仅在受控总表使用。
- `Statement`：忠实于受访者的一句话，不把个案直接升级为规律。
- `Context`：影响结论的背景与约束；涉及身份的细节先概括。
- `Applicability`：这条经验适用于谁、哪些条件下不适用。
- `Candidate Pages`：多个 ID 用英文分号分隔；暂时无法归类写 `UNPLACED`，建议新专题写 `NEW_PAGE`。
- `Verify`：`YES`、`NO` 或 `PENDING`；`FACT` 通常需要 `YES`。
- `Relation`：如 `supports:E-002-03`、`conflicts:E-004-06`，多个关系用英文分号分隔。

`Type` 只能选 `FACT`、`EXP`、`METHOD`、`JUDGEMENT`、`WARNING`、`RESOURCE`。案例不是卡片类型。

`Confidence` 表示距离可公开总结的证据距离：`A` 为官方或多个独立来源支持，`B` 为多位受访者印证，`C` 为单一个案，`D` 为仅供线索。它不代替事实核验或公开授权。

卡片状态：`RAW → REVIEWED → CLUSTERED → INTEGRATED`；无法继续处理时用 `HOLD`，失效或不再需要时用 `ARCHIVED`。进入节点后不要删除原卡。

## Nodes

`Node ID`、`核心命题`、`支持卡 ID`、`反例卡 ID`、`适用条件`、`潜在页面`、`编辑状态`、`Node Editor`、`证据与局限`。

节点编号如 `K-R-001`、`K-C-001`。支持卡与反例卡用英文分号分隔。编辑状态使用 `DRAFT`、`REVIEW`、`READY`、`HOLD`、`INTEGRATED`。只有 `READY` 节点可进入常规发布队列。

## Pages

`Page ID`、`页面槽位`、`范围`、`Include`、`Exclude`、`Page Owner`、`状态`、`现有 Wiki 页面`、`备注`。

页面槽位是后台词表，不保证每个槽位都已有独立网页。`状态` 只用 `EXISTING`（已有独立页）、`SECTION`（现有汇总页中的章节）、`PLANNED`（仅后台规划）。负责人待团队实际指定，不填虚构姓名。

## Publish Queue

`Queue ID`、`Node ID`、`Target Page`、`Change`、`Owner`、`Reviewer`、`Status`、`事实核验`、`隐私审查`、`老师批准`、`PR / 页面链接`、`复审日期`。

队列状态使用 `DRAFT`、`REVIEW`、`READY`、`HOLD`、`PUBLISHED`。`READY` 只表示内部审稿完成；公开合并还需要科协老师批准。批准记录由科协内部保存，表格只填写批准结果。

## 编号与填写约定

| 对象 | 格式 | 例子 |
| --- | --- | --- |
| 访谈来源 | `INT-三位数字` | `INT-001` |
| 经验卡 | `E-来源三位数字-两位序号` | `E-001-07` |
| 知识节点 | `K-领域字母-三位数字` | `K-R-004` |
| 案例叙事 | `CASE-三位数字` | `CASE-001` |
| 发布动作 | `PUB-三位数字` | `PUB-001` |

编号只增不复用。日期统一 `YYYY-MM-DD`；未知日期留空，不用虚构日期。多人共同负责时仍指定一个主负责人。状态变更由实际完成人填写；不通过改写旧卡来消除相互矛盾的证据。
